# 出勤模拟器 

打开 `index.html` 即可离线游玩。页面使用 Lit 3 与 esbuild，已附带构建产物 `dist/app.js`，日常游玩不需要安装 Node.js 或启动服务器。所有 1,394 首曲绘和 Rating 分数框已缓存到本地；请保留整个游戏文件夹。

## 开局与词条

首次进入选择职业、玩家姓名、舞萌 ID，以及随机抽出的三个初始词条中的一个。姓名留空默认为“神秘人”，舞萌 ID 留空默认为“Maimai”。职业在本周目固定。已有春季存档自动补齐新系统并继续原进度，设置中的“重新开始”可进入角色创建。

词条效果依据 `data/maimai-talent-tags.md`。初始三选一会保留抽选结果，刷新不会重抽；完成任一结局后开启下一周目，才将“龙B！”加入初始池。后续词条按曲目游玩次数、B50、分类成绩等里程碑自动获得，详情和条件在词条列表查看。属性加成只结算一次；“越打越有”的加成只在连续第五轮起临时生效，等待至少 15 分钟清除连续轮数。“手比脑快”解锁可切换的凭手感模式，以更多体力消耗换取有效底力。

上班族周一至周五 09:00–18:00 固定上班，心情 -15，工作日只能利用下班后的完整时段出勤。周末休息。学生按周课表逐门决定上课或逃课。其他行动不能跨越尚未处理的课程或工作。

## 学业

- 初始学力 70，范围 0–100。专业课上课学力 +5 / 心情 -7；水课学力 +2 / 心情 -3。
- 水课逃课：学力 -4，35% 概率被抓，再扣学力 2、心情 5。
- 专业课逃课：学力 -12，75% 概率被抓，再扣学力 5、心情 10。
- 逃课不消耗该课程的时间。学力归零进入挂科、触发老师约谈，打歌状态 -0.20。
- 补习消耗 2 小时、心情 3，学力 +12；学力恢复到 20 可以解除挂科。
- 每次新进入挂科触发一次约谈。第 3 次约谈，或连续挂科满 10 个结算日，进入肄业结局。约谈消耗至多 20 分钟，不跨越下一门课程。

## 出勤

机厅 10:00 开门，**23:30 结束游玩**。手机显示三家机厅的当前模拟人数、双人机组数量。早上和饭点较少，19–22 点略多；每半小时及上机后会发生随机变化，可能有人离店。交通花费包含往返，但时间按实际去程 / 回程分别推进。公共交通去较远的老街店 / 商场店为往返 ¥4、36 / 30 分钟，共享单车为 ¥5、56 / 46 分钟；界面与实际出行共用交通报价。饮品消耗 5 分钟。学生仍需午夜前回家，课业日也为回程与用餐留出空闲。挂壁和上班族可以打到闭店后再吃饭、回家，最晚行动截止为次日 04:00。

| 模式 | 个人花费 | 游玩曲数 | 自选 | 净上机时间 |
| --- | ---: | ---: | ---: | ---: |
| 单开 | ¥6 | 3 首 | 3 首 | 12 分钟 |
| 拼机 | ¥6 | 4 首 | 自选 2 首 + 拼机伙伴 2 首 | 16 分钟 |

拼机时双方同时打相同的四首，每人独立付 ¥6。机厅按全员同模式估算排队：单开人数为 `people` 组，拼机为 `ceil(people/2)` 组；完整等待轮数为 `floor(groups / cabinets)`。等待时间等于轮数乘净上机时间，因此拼机一轮更长，但排队同时服务两人。

到店加入队伍，每个 PC 结束后重新计算等待截止时间；投币只消耗净上机时间，需单独等待到轮次。排队时等待、补给、群聊消耗的时间会同时推进队伍，不重复收费或重复扣等待时间。可以随时结束上机去吃饭，不必先排下一轮。

## 手套、体力与社交

- 开局赠送 100 耐久棉线手套；棉线手套 ¥8，耐磨手套 ¥25 / 240 耐久。每曲按难度磨损，耐久不够一轮时禁止上机，可在家或机厅更换。
- 体力通常上限 100。每曲消耗为 `(1 + 总音符数/180) * (max(3,定数)/10)^1.7`，凭手感模式再乘 1.35。难度和物量越大，消耗越高；不足 12 时不能上机，体力低于 55 逐渐减分。
- 每瓶饮料 600 ml，每首消耗 60 ml。喝完失去饮品增益并额外降低预期达成率 0.3 个百分点。补给可重新买饮品或免费补白水。
- 移除家中小憩和机厅休息入口及效果。白天仅等待和吃饭恢复体力：等待每分钟 +0.35，未排队时可等待 15 分钟；回家吃饭 / 面馆 / 快餐 / 火锅分别 +30 / 40 / 45 / 60。普通娱乐、刷视频和交通不回体。正常睡眠仍恢复体力，受熬夜影响。
- 饭点定义为 11:00–14:00、17:00–20:00；非饭点且本次出勤累计体力消耗低于 25、剩余体力至少 60 时可不吃饭直接回家。跳过吃饭不恢复体力，也不消耗用餐时间。
- 游戏状态每日结合心情随机产生：极差、还行、普通、不错、完美，分别有负面或正面成绩修正。低状态更容易发生不利事件。
- 营业时间内任一机厅人数超过 10 时，群聊触发“大B队来了”，部分 NPC 犹豫并暂停模拟出勤 45 分钟。每店只在人数越过阈值时触发，冷却 3 小时，读档或反复查看不会刷消息。
- 舞萌群从 8 组本地对话中抽取聊天记录。发言消耗 5 分钟，每天前 5 次增加所有群友 3 点眼熟度，后续仍能聊天但不再刷好感。
- 30 个固定 NPC ID 各自保存 Rating、眼熟度、曲风、星星 / 键盘偏好和激进程度。游戏时间推进时模拟选曲与成绩，优秀发挥会提高 Rating；只有官方定数 >=12.4 且达成率 >100.5% 或 AP 的成绩才在群里炫耀，使用曲名与成绩，不带难度，其他群友以“这么强！？”、“龙B来了”等十种回复回应；每天最多两段炫耀对话，单人每天最多一次。选曲以自身 Rating / 1110 为基准，容许向上挑战约 0.5–1.18 定数，并加权个人偏好。玩家可针对拼机伙伴选的每首歌独立选择难度；同一 PC 的拼机伙伴选曲及双方难度在刷新、存档恢复后保持一致。眼熟度达到 40 后有 35% 概率让玩家选 3 首、拼机伙伴选 1 首；每轮总计仍为 4 首。

## 成绩与底力

**达成率最高 101.0000%，Rating 封顶计算到 100.5%。** 单谱 Rating 为 `floor(ds * min(achievement, 100.5) / 100 * coefficient)`，评级阈值包括 SSS+ 100.5、SSS 100、SS+ 99.5。总 Rating 取旧曲 B35 + 新曲 B15，同曲不同难度分别计分。

星星和键盘底力分别保存。参考 ChiffonMai 的 MaiTagsManager，导入 DXRating 社区标签，按曲名、SD / DX 和难度匹配到 1,305 张谱面。仅有“星星谱”时星星权重为 0.85，仅有“键盘谱”时为 0.15；错位、一笔画标签提供至少 0.65 的星星权重。没有这些技术标签时，使用 `SLIDE / 总音符数 * 2.4`，夹在 0.12–0.88 的估算权重。界面分别标出来源；这是社区分类与音符数量近似，不是完整谱面时序分析。对应底力影响和成长随权重变化。

每张谱面单独累计熟练度，即使没刷新最佳成绩也增长。初见预期修正 -0.55 个百分点；复打修正为 `min(0.85, 0.12 * log2(次数+1))`。心情、饮品、疲劳与模拟判定波动仍会影响实得成绩，复打并不保证每次都刷新纪录。

新增第三项底力“读谱力”，初始 9.8。其修正为 `clamp((reading-9.8)*0.065,-0.4,0.65)`；初见使用全部修正，复打使用 60%。随每首成长，初见成长略多。“读谱天才”等词条也会提高该数值。

FC / FC+ / AP 与 SSS 评级独立，由模拟判定统计计算：

- **Full Combo / FC**：没有 MISS。
- **Full Combo+ / FC+**：没有 GOOD 或 MISS。
- **All Perfect / AP**：没有 GREAT、GOOD 或 MISS，BREAK 非最高 PERFECT 可以令 AP 达成率低于 101。

模拟器按 TAP / HOLD / SLIDE / TOUCH / BREAK 数量独立生成判定，再计算基础分和 BREAK 加分。基础权重分别为 500 / 1000 / 1500 / 500 / 2500，普通音符 GREAT 为 80%、GOOD 为 50%。BREAK 的 PERFECT 50 / 100 保留基础分，加分分别为 0.75 / 0.5；GREAT 80 / 60 / 50 的基础比例与名称一致、加分均为 0.4；GOOD 基础比例为 0.4、加分为 0.3。所有 BREAK 的平均加分最多贡献 1 个百分点，没有 BREAK 的谱面没有该加分。

参考 ChiffonMai 的 `DetailedJudgement.dart` 与 `AchievementRateCalculatorPage.dart` 核对数值规则。MISS 概率独立于精度损失，受底力、熟练度和读谱力影响，因此达到 SSS 也可能没有 FC。此为养成游戏的随机模拟，概率参数是本作设计，不是 ChiffonMai 或官方音符时序重放。最佳达成率与最佳连击徽章分别保留。

曲名开头带 `[...]` 前缀的谱面统称宴曲，自动推荐与拼机伙伴选曲均排除。自选仍能游玩和留下记录，但 Rating 为 0，不进入 B50；读取旧存档时也会移除宴曲的 Rating。曲库可按国服版本、分区、星星 / 键盘、鬼歌 / 吃分推荐及宴曲筛选。其余 19 种社区技术标签隐藏，不参与查询与谱面详情展示。每曲最多触发一次对应段落判定：普通状态 40%，低状态 45%，高状态 35%。拆弹按星星力 60% + 读谱力 40% 判定；其余段落按对应技能加权。通过不改变成绩，失败将一小段成功音符改为 MISS，重新计算基础分、BREAK 加分和 FC/AP；结果与日志展示段落事件。该机制是模拟器设计，不包含实际谱面段落时间轴。选曲按每个位置逐首更换；上机界面显示整数等级，定数小数部分 >=0.5 显示为 `+`（如 12.5 → 12+）。搜索 `12+` 可按等级筛选。谱面详情与 B50 图片保留精确定数。

## 手元、机器人与 B50

鬼歌每次按拟合定数计算表现，初见额外降低 0.45 个百分点；成长乘 1.3。吃分推荐预期达成率 +0.16 个百分点，成长乘 0.7。BASIC 不加这两种标签，ADVANCED 不加吃分推荐，所有定数低于 10.0 的谱面均不加标签。Rating 仍按官方定数计算。

刷视频消耗 30 分钟，心情 +7。65% 概率推送定数与当前能力相差不超过 1 的鬼歌手元，理解程度随读谱力随机决定。点击“大彻大悟”会免除这张谱面的鬼歌初见额外惩罚，星星谱恢复原定数，键盘谱使用拟合与原定数的中值并向下保留一位小数；“似懂非懂”仅免除额外初见惩罚。一般初见惩罚仍保留。学习效果按谱面存档，不会降级覆盖。

群聊底部显示 `@bot查看指令`。输入 `@bot` 查看帮助，`B50` 生成当时成绩的 PNG 图片，`jk` / `几卡` 查询实时机厅人数；机器人指令不消耗时间和眼熟度次数。输入 `f8fq` 会回复“不要念辣个”。B50 页可切换列表 / 成绩图并下载，群内使用相同生成器。五列曲绘卡片参考 ChiffonMai 的 `B50GameCardWidget.dart` 和 maimaiDX 的 `core/image/best50.py`，使用本作配色；不伪装真实查分账号。曲绘通过本地数据资源绘制，离线导出不会污染 Canvas。

## 结局与存档

好结局要求 Rating >=16000。恋爱事件始于第二次完成上机，后续至少间隔三次出勤，最终事件严格要求 Rating >13000；正确选项依次为 1、2、1、1，相遇消耗 10 分钟。其他结局为金钱耗尽、心情耗尽、欠租、肄业，以及 6 月 30 日结束时的普通结局。

新版保存到 `attendance-simulator-v2`，不会覆盖旧版 `attendance-simulator-v1`。设置中可以迁移旧存档，保留余额、心情、成绩与关系，将原底力映射为相同的星星 / 键盘值，回到对应第 N 天 08:00；旧出勤中间状态不迁移。可导入 / 导出 JSON 存档。

已有 v2 存档原地补全身份、第三项底力、手套、体力、饮料余量、NPC 与聊天记录等默认值，保留资金、成绩、课表和当前出勤阶段。初始抽签与周目计数分别存入 `attendance-setup`、`attendance-run`。

## 数据与素材

曲库来自 [水鱼查分器公开 API](https://www.diving-fish.com/api/maimaidxprober/music_data)，快照日期 2026-09-14，共 1,394 首、5,537 张谱面。曲库版本分组与故事月份独立，页面显示国服版本名称，SD / DX 分开汇总难度。`data/cn-versions.js` 依据落雪 2026-09-15 公开曲库，按曲名、SD / DX 与谱面引入版本匹配 1,393 首；唯一未匹配的 Link(CoF) 保留历史 ORANGE 标注。当前版本为舞萌DX 2026，B15 随国服引入版本核算，读取旧存档会重新分组。故事日期不限制曲库快照。

曲绘主要来自 `https://www.diving-fish.com/covers/`，备用源为 `https://assets.lxns.net/maimai/jacket/`。同曲标准 / DX 或其他谱面 ID 可共用曲绘。全部转为 160×160 WebP 本地缓存。详细来源见 `data/assets-sources.json` 与 `data/covers-report.json`。

名牌来自 [maimaiDX 的 CN1.55 公开素材包](https://github.com/Yuri-YuzuChaN/maimaiDX) 与落雪素材服务。Rating 框使用华立国服官网公开原图 `https://maimai.wahlap.com/maimai-mobile/img/rating_base_{color}.png`，共 11 档，左侧为 DX RATING。图片未经改绘，本地存于 `assets/rating/wahlap`；下载来源和 SHA-256 写入该目录的 `sources.json`。运行 `node scripts/import-cn-rating.cjs` 可更新。数字使用已有数字素材按五个槽位叠加。称号使用圆角胶囊样式。

收藏条件来自落雪公开 `plate/list?required=true`、`trophy/list?required=true`，通过 ChiffonMai 的收藏模块确认数据来源。收录 397 块名牌（含 71 块极 / 将 / 神成就名牌）、1,837 个称号（已移除 1,162 个要求觉醒的称号），名牌图片全部本地缓存。所有收藏页支持全部 / 已解锁 / 未解锁筛选，并可与名称搜索组合。逐项使用 API 指定的曲目、谱面类型、难度和成绩条件；舞系要求中的 Re:MASTER 也计算。缺失必要谱面不会误判解锁。FULL SYNC 与尚无可模拟条件的活动称号显示未开放，不虚构解锁条件。

每天首次完成上机后自动签到，为选定奖励增加 2 点进度，达到目标即可解锁。未选择奖励或当前奖励已完成时，自动选择下一件未完成奖励；同一天重复游玩、切换奖励或读档不会重复签到。区域装饰改编为选定区域累计游玩 10 PC 解锁；展示原始条件与本作条件，无旅行伙伴养成。移动距离称号按实际去程与回程公里数累计：三家机厅单程分别为 1.8 / 3.2 / 2.4 km，与交通方式无关，到店和回家时各计一次。取消出行、失败的出行、机厅内打歌与等待不增加距离；原门槛 100 / 1,000 / 10,000 / 100,000 km 保留。旧存档没有历史距离记录，从更新后实际移动开始累计；已装备的删除称号回退为初始称号。

收藏页支持切换分类、搜索、查看进度和装备名牌 / 称号；玩家头像可上传 PNG、JPEG 或 WebP（最大 5 MB），裁剪压缩后随存档保存。

鬼歌 / 吃分推荐使用 [水鱼 chart_stats](https://www.diving-fish.com/api/maimaidxprober/chart_stats) 的拟合定数和样本数，并与 [落雪公开曲库](https://maimai.lxns.net/api/v0/maimai/song/list?notes=true) 的官方定数核对。两站定数一致、样本数至少 100，且“拟合 - 官方”达到 +0.3 / -0.3 才标为鬼歌 / 吃分推荐。快照覆盖 5,475 张有拟合数据的谱面，按本次难度限制保留 199 张鬼歌、315 张吃分推荐。没有取得落雪公开拟合值，因此这不是多查分器拟合共识；缺数据、样本少或定数冲突的谱面不加标签。原始差值、样本数、落雪定数在谱面详情展示，阈值和来源写入 `data/chart-meta.js`。
